Install

{{release_note}}

You need R.E.P.O. from Steam. Everyone you play with in a Haulnet game needs Haulnet and the same game version.

With a mod manager

From the first release, Haulnet is published on Thunderstore for R.E.P.O. and installs like any other mod in r2modman, Gale or the Thunderstore app: search for Haulnet, install, start the game from the manager. The manager installs BepInExPack, Haulnet's only dependency, by itself.

By hand

  1. Install BepInExPack (BepInEx 5) into the game folder and start the game once, so BepInEx creates its folders.
  2. Download the release zip and extract it into REPO/BepInEx/plugins. You get BepInEx/plugins/Haulnet/Haulnet.dll and BepInEx/plugins/Haulnet/server/luxon_server.exe; keep the server folder next to the DLL.
  3. Start the game. BepInEx/LogOutput.log contains a line like [Info : Haulnet] Haulnet 0.4.0 loaded.

{{manual_download}}

From source

Needs the game with BepInEx 5 installed and the .NET SDK 8 or newer:

git clone https://github.com/haulnet/haulnet-repo.git
cd haulnet-repo
copy mod\Directory.Build.user.props.example mod\Directory.Build.user.props
rem set GameDir in that file to the folder with REPO.exe
dotnet build mod/Haulnet.sln -c Release

The build downloads the pinned LuxonServer release, checks its SHA-256 and, with DeployToGame set to true, copies the plugin into BepInEx/plugins/Haulnet. Details are in the README.

First start: Windows Firewall

The first time you host “On my PC”, Windows may ask whether luxon_server and R.E.P.O. may use the network. Allow it for the networks your friends come from (private networks for a LAN or most VPNs). Without it, friends get no answer from your PC.

Update and remove

  • Mod manager: update or uninstall Haulnet in the manager.
  • By hand: to update, replace the BepInEx/plugins/Haulnet folder with the new one; to remove, delete that folder. Settings stay in BepInEx/config/haulnet.repo.cfg until you delete it.
  • With Haulnet removed, the game is exactly as before. Haulnet never changes game files or system settings.
