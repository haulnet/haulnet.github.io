Install

{{release_note}}

Requirements

  • R.E.P.O. from Steam, on Windows. Everyone you play with in a Haulnet game needs Haulnet and the same game version.
  • BepInExPack (BepInEx 5), Haulnet's only dependency.
  • Hosting “On my PC” runs a small Windows server program next to the game; joining needs nothing extra.

By hand

  1. Find the game folder. In Steam, open Library, right-click R.E.P.O. and choose Manage → Browse local files. The folder that opens contains REPO.exe.
  2. Put BepInExPack into it. On the BepInExPack page, press Download and open the zip. Copy everything inside its BepInExPack folder (winhttp.dll, doorstop_config.ini, the BepInEx folder) into the game folder, next to REPO.exe.
  3. Start the game once and close it. BepInEx creates its folders: the game folder now has BepInEx/plugins and BepInEx/LogOutput.log.
  4. Add Haulnet. Download the release zip and extract it into BepInEx/plugins. You get BepInEx/plugins/Haulnet/Haulnet.dll and BepInEx/plugins/Haulnet/server/luxon_server.exe; keep the server folder next to the DLL.
  5. Start the game. BepInEx/LogOutput.log contains a line like [Info : Haulnet] Haulnet version loaded. and the region page has a HAULNET tab. If the line or the tab is missing, see No HAULNET tab.

{{manual_download}}

If you already play with mods through a mod manager, the plugins of that profile are not in the game folder. Put the Haulnet folder into that profile's BepInEx/plugins instead; the manager has a command that opens the profile folder.

First start: Windows Firewall

The first time you host “On my PC”, Windows may ask whether luxon_server and R.E.P.O. may use the network. Allow it for the networks your friends come from (your home network, the Radmin VPN or WireGuard adapter). Without it, friends get no answer from your PC.

Update and remove

  • Update: replace the BepInEx/plugins/Haulnet folder with the new one.
  • Remove: delete BepInEx/plugins/Haulnet. Settings stay in BepInEx/config/haulnet.repo.cfg and the cached server list in BepInEx/cache/Haulnet until you delete them.
  • Remove BepInEx too: delete the BepInEx folder, winhttp.dll, doorstop_config.ini and .doorstop_version from the game folder; this removes every BepInEx mod and its settings.
  • With Haulnet removed, the game is exactly as before. Haulnet never changes game files or system settings.

From source

For developers and testers. You need the game with BepInEx 5, the .NET SDK 8.0, and internet access for the first build.

  1. Clone haulnet/haulnet-repo.
  2. Copy mod/Directory.Build.user.props.example to mod/Directory.Build.user.props and set GameDir in it to the folder with REPO.exe.
  3. Run dotnet build mod/Haulnet.sln -c Release.

The build downloads the pinned LuxonServer release, checks its SHA-256 and, with DeployToGame set to true, copies the plugin into BepInEx/plugins/Haulnet. Details are in the README.
