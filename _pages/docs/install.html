Install

{{release_note}}

Requirements

  • R.E.P.O. from Steam, on Windows. Everyone you play with in a Haulnet game needs Haulnet and the same game version.
  • BepInExPack (BepInEx 5), Haulnet's only dependency.
  • Hosting “On my PC” runs a small Windows server program next to the game; joining needs nothing extra.
  • Not tested yet: Linux, Proton and Steam Deck.

By hand

  1. Install BepInExPack into the game folder and start the game once, so BepInEx creates its folders.
  2. Download the release zip and extract it into REPO/BepInEx/plugins. You get BepInEx/plugins/Haulnet/Haulnet.dll and BepInEx/plugins/Haulnet/server/luxon_server.exe; keep the server folder next to the DLL.
  3. Start the game. BepInEx/LogOutput.log contains a line like [Info : Haulnet] Haulnet version loaded.

With a mod manager

Haulnet is planned for Thunderstore, so that it installs like any other mod in r2modman, Gale or the Thunderstore app, with BepInExPack installed by the manager. This page will say so when it is there.

First start: Windows Firewall

The first time you host “On my PC”, Windows may ask whether luxon_server and R.E.P.O. may use the network. Allow it for the networks your friends come from (your home network, the Radmin VPN or WireGuard adapter). Without it, friends get no answer from your PC.

Update and remove

  • Update: replace the BepInEx/plugins/Haulnet folder with the new one (in a mod manager: update Haulnet there).
  • Remove: delete BepInEx/plugins/Haulnet. Settings stay in BepInEx/config/haulnet.repo.cfg and the cached server list in BepInEx/cache/Haulnet until you delete them.
  • With Haulnet removed, the game is exactly as before. Haulnet never changes game files or system settings.

From source

For developers and testers. You need the game with BepInEx 5, the .NET SDK 8 or newer, and internet access for the first build.

  1. Clone haulnet/haulnet-repo.
  2. Copy mod/Directory.Build.user.props.example to mod/Directory.Build.user.props and set GameDir in it to the folder with REPO.exe.
  3. Run dotnet build mod/Haulnet.sln -c Release.

The build downloads the pinned LuxonServer release, checks its SHA-256 and, with DeployToGame set to true, copies the plugin into BepInEx/plugins/Haulnet. Details are in the README.
