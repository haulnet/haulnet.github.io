Troubleshooting

Every message Haulnet shows, by the title you see in the game, with what it means and what to do.

The message texts on this page are read from Haulnet's own English text table ({{messages_source}}) when the site is built. Words in italics are filled in by the game, such as a server name or a port.

Choosing a server

None of that city's servers can take a new game right now: each one is down, full, updating, runs a version the current game does not work with, or answers but has no game server running. Look at servers.haulnet.cc for the live state, pick another city or try later.

If every city says this while servers.haulnet.cc shows them online, your network probably blocks the servers' status check (TCP port 27080). Try another network, or a server by address.

The server reached the limits its operator set. Pick another server or city; games already running there are not affected.

The server waits for its running games to end, then restarts with the new version. Try again in a few minutes.

Check the spelling. If the name is right, its DNS is broken or the server is gone; ask whoever gave you the address.

The reason in brackets is one of:

An IPv6 address with a port goes in brackets: [2001:db8::1]:27000. Ports are numbers from 1 to 65535; without a port, 27000 is used.

The computer at that address is on, but its game server (LuxonServer) is not. A ping on the row only shows that the machine answers. If you run the server, start it and check that UDP 27000–27002 are open; otherwise ask its owner.

Connecting and staying connected

On a server (the first text): the server is down, or UDP to it is blocked on the way: by the server's firewall (it must allow UDP 27000–27002), by your network or by a VPN. Try another server; if you run it, check that it is running and the UDP ports are open.

Joining a friend's PC (the other texts): none of the host's addresses answered. The list contains every network address of the host's PC, followed by the port; unfamiliar ones (starting with fd or 2001:0:) are normal. The host sees the same problem as FRIEND NOT CONNECTED, and the fixes are on the host's side. If you share a VPN, make sure both of you are connected to it.

The server or the host's game went away during the game. When the server is back (or the host has created the game again), create or join the game again.

The game was updated and Haulnet switched itself off instead of risking a broken game. Photon Cloud games keep working. Look for a Haulnet update; if invites to Haulnet games stop working after a game update, update Haulnet too.

Ask the host for the password.

In R.E.P.O. the host's kick button bans the player from the current game, with or without Haulnet; the first time you see the game's own Kicked message. The ban ends when the host returns to the main menu and creates a new game.

Hosting on your PC

The reason is one of:

  • Server file is missing: BepInEx/plugins/Haulnet/server/luxon_server.exe is not there. Reinstall Haulnet and keep the server folder next to the DLL.
  • Port in use: another server or a second game uses it. Close that program or choose another port in the UDP PORT box.
  • Could not start / stopped unexpectedly: Windows or security software blocked luxon_server.exe, or it crashed. The message shows the system's reason and the server's last output; the full log is in BepInEx/LogOutput.log.

Enter a number from 1024 to 65533; the default is 27000.

Your friend cannot reach your PC. Check, in this order: Windows Firewall allows luxon_server and R.E.P.O. (how); you are both connected to the same VPN or network; or your router forwards those UDP ports to your PC. If none of that is possible, create the game on a Haulnet server instead: Reaching the host's PC.

The game's own messages

If you see the game's own Disconnected message (for example ClientTimeout) instead of a Haulnet message, Haulnet did not recognise the problem. Note what you did and report it with the logs (below). Haulnet does not change Photon Cloud connections.

Logs and reporting a problem

  • Haulnet writes to BepInEx/LogOutput.log in the game folder (its lines look like [Info : Haulnet] …); the game's own log is Player.log in %USERPROFILE%\AppData\LocalLow\semiwork\Repo.
  • Report problems on GitHub with the game version, the Haulnet version, what you did and the message you saw. Logs contain IP addresses: remove them or send the log privately to contact@haulnet.cc.
  • A problem with a listed server goes to the server list.
  • Security problems: security@haulnet.cc.
