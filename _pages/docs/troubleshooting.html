Troubleshooting

Every message Haulnet shows, by its title. Texts in italics are filled in by the game, such as a server or a port.

Servers

NO SERVER

City: no server answers its status check, accepts new games and runs a compatible version.

Every server of that city is down, full, updating or runs a LuxonServer version the current game does not work with. Look at servers.haulnet.cc for the live state, pick another city or try later.

SERVER IS FULL

Server does not accept new games (its status says accepting: false).

It reached the limits its operator set. Pick another server or city; games already running there are not affected.

SERVER IS UPDATING

The server is updating and starts no new games until it is done.

It waits for the running games to end, then restarts with the new version. Try again in a few minutes.

SERVER NOT FOUND

The name host does not resolve to an address.

Check the spelling. If the name is right, its DNS is broken or the server is gone; ask whoever gave you the address.

WRONG ADDRESS

“text” is not a server address.

Use host or host:port, for example play.example.org or 203.0.113.5:27100. An IPv6 address with a port goes in brackets: [2001:db8::1]:27000. Ports are numbers from 1 to 65535.

HAULNET: NO CONNECTION

No answer from server on UDP port.

The server is down, or UDP to it is blocked on the way: by the server's firewall (it must allow UDP 27000–27002), by your network, or by a VPN. Try another server; if you run it, check that LuxonServer is running and the UDP ports are open.

Hosting on your PC

HAULNET: SERVER ERROR

The server on your PC could not start, with one of these reasons:

  • Server file is missing: server/luxon_server.exe is not next to the plugin. Reinstall Haulnet; an antivirus may also have removed it (then restore it and add an exception).
  • UDP port … is already in use by another program: another server or a second game uses it. Close that program or choose another port in the UDP PORT box.
  • Could not start the server / The server stopped unexpectedly: Windows or an antivirus blocked luxon_server.exe, or it crashed. The message shows the system's reason and the server's last output; the full log is in BepInEx/LogOutput.log.
WRONG PORT

The port must be a number from 1024 to 65533. The game uses it and the next two ports.

HAULNET: FRIEND NOT CONNECTED

Friend got no answer from your PC on UDP first–last.

Your friend cannot reach your PC. Check, in this order: Windows Firewall allows luxon_server and R.E.P.O. (how); you are on the same LAN or the same VPN; or your router forwards UDP first–last to your PC. If none of that is possible, create the game on a community server: Reaching the host's PC.

Joining a friend

No answer from the host's PC

No answer from host's PC (addresses).

None of the host's addresses answered. The host sees the same problem as FRIEND NOT CONNECTED; the fixes are on the host's side. If you share a VPN, make sure both of you are connected to it.

HAULNET IS OFF

Haulnet is not compatible with this game version yet. You are playing through Photon Cloud as usual.

The game was updated and Haulnet switched itself off instead of risking a broken game. Wait for a Haulnet update; Photon Cloud games keep working.

WRONG PASSWORD

The lobby password you entered is not correct. Ask the host for it.

BANNED

The host has banned you from this game.

Logs and reporting a problem

  • Haulnet writes to BepInEx/LogOutput.log in the game folder (its lines look like [Info : Haulnet] …); the game's own log is Player.log in %USERPROFILE%\AppData\LocalLow\semiwork\Repo.
  • Report problems on GitHub with the game version, the Haulnet version, what you did and the message you saw. Logs contain IP addresses: remove them or send the log privately.
  • A problem with a listed server goes to the server list.
  • Security problems: security@haulnet.cc.
