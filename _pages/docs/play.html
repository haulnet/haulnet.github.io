Play

Open Private game or Public game as usual. The region page gets two tabs: HAULNET and PHOTON CLOUD (the game's own regions, unchanged). The tab you used last opens next time. Pick where the game lives, exactly like picking a region.

The HAULNET tab

Your own places come first, the public cities last:

RowWhat it does
On my PCPrivate games only. Enter the UDP port (the last one is prefilled, 27000 by default); a server starts next to your game on that port and the next two, and stops when you return to the main menu.
+ Server by address...Type host or host:port (port 27000 if not given; IPv6 as [2001:db8::1]:27000; Ctrl+V pastes). The last address that worked is prefilled. The server does not need to be listed anywhere.
This PC · nameShown when a haulnet-server runs on this PC.
Saved and recent serversOne row each, with the server's name or address: the servers you saved in the config file, then up to five you played on recently. The right side shows the ping, full, updating, or — when the server does not answer.
One row per city, e.g. Europe [Moscow]The cities of the public server list, with ping. Haulnet checks every server of the city and uses one that answers, accepts games and runs a compatible version: for a private game the least busy of the closest ones, for a public game the busiest one, so public players of a city meet. Cities are ordered by your ping and their stability over the last day and week, closest and most stable first.

On a server, a private game works as usual: invite friends through Steam. A public game opens the game's own Public game page, so Random matchmaking and the Server list (with Create new) work on that server.

How friends join

Friends accept the Steam invite or use Join game in the Steam friends list, as always. The invite says where the game lives: on a server, or on the host's PC with all of the host's addresses and the port. Haulnet uses the address that answers first. Under “Press T to chat” the lobby shows where you are:

  • Haulnet · on your PC · UDP 27000-27002 for the host of an “On my PC” game;
  • Haulnet · host address for a friend connected to the host's PC;
  • Haulnet · server name (address) or Haulnet · server address on a server.

If a friend cannot connect, the friend sees which addresses and port were tried and the host sees who got no answer (see Troubleshooting). Lobby password, kick and ban work too; in a Haulnet game the host's mod checks them, so a refused player may appear in the lobby for a moment before being removed.

Reaching the host's PC

“On my PC” needs a network path from your friends to your PC. Haulnet does not guess or set one up; anything that connects the two PCs works:

SituationWhat to do
Friends far away: Radmin VPN (free, Windows)Everyone installs Radmin VPN and joins the same Radmin network first; the invite then contains your Radmin address. Radmin links the PCs directly when it can and shows Relay/TCP when it cannot (then the connection is slower).
Friends far away: WireGuardPut your PC and your friends' PCs into one WireGuard network first; at least one of them needs an address the others can reach (a VPS or a forwarded port). The invite then contains your WireGuard address.
Same home or LAN partyAllow the Windows Firewall prompt; friends use your local address from the invite.
Both sides have IPv6Your router must let incoming UDP through to your PC.
Router with a public IPv4 addressForward UDP 27000–27002 (or your port and the next two) to your PC.
None of these (most home connections)Create the game on a Haulnet server instead: nobody needs to reach your PC.

Ports: the server on your PC uses the port you enter and the next two (UDP 27000–27002 by default). A short address check between a friend and the host uses UDP 47777; it is optional. Windows Firewall may ask whether luxon_server and R.E.P.O. may use the network: allow it.

Config file

Settings live in BepInEx/config/haulnet.repo.cfg (created at the first start; edit it while the game is closed):

SettingMeaning
[Hosting] PortUDP port for “On my PC”; it uses this port and the next two.
[Servers] SavedServers always listed on the region page, as Name=host[:port] separated by ;, for example Dacha=play.example.org;Office=203.0.113.5:27100.
[Servers] RecentFilled automatically: servers you played on recently.
[Servers] LastAddressFilled automatically: the last address typed in + Server by address whose game opened.
[Servers] LastTabFilled automatically: the tab that opens first.
[Servers] RegistryUrlEmpty uses the Haulnet list. A community can point it at its own list in the same format: https://, file:///, or http://localhost for a list on this PC (the game refuses plain http:// to other hosts).
