Haulnet documentation

Haulnet is a free, open-source mod for R.E.P.O. It lets a game live on your own PC, on a Haulnet server or on any server by address, instead of Photon Cloud.

It is useful when no Photon Cloud region is close to you (a Haulnet server can stand in any city), when you want a server of your own for your friends or for everyone, and when you want to play directly with friends from your own PC, with no server in between. Who it's for.

How it works

R.E.P.O. uses Photon for multiplayer: every player connects to a Photon server, which relays the game between them. That server normally lives in Photon Cloud, the game's online service, even when both players sit on the same network. Haulnet points the game at a different, Photon-compatible server instead: LuxonServer, an open-source implementation by its own author.

  • On my PC: the host's Haulnet starts LuxonServer next to the game when the host creates the game, and stops it when the host returns to the main menu, like Minecraft's “Open to LAN”.
  • Listed Haulnet servers: the public list at servers.haulnet.cc shows official servers run by the Haulnet project and community servers, by city. Each runs the haulnet-server package.
  • Server by address: any server you or a friend runs, listed or not; its address goes into the row + Server by address...

The Steam invite carries where the game lives, so friends follow it as usual. Until you pick a row in the HAULNET tab, the game plays exactly as without the mod.

Privacy and safety

  • Haulnet sends no telemetry. It downloads the public server list, reads the servers' uptime from the Haulnet server monitor (monitor.haulnet.cc), pings the listed servers and asks them for their status (counts and versions only).
  • Whoever runs the server of a game sees the players' IP addresses and Steam IDs. The game also sends the server the Steam sign-in ticket it normally sends to its own online service; a Haulnet server does not need it and does not check it. On your PC the server is yours; on a listed server it is its operator's, named in the list. Play on servers whose operator you trust.
  • Official Haulnet servers keep a technical log with connection times, IP addresses and Steam IDs, at most 30 MB per server; older lines are overwritten. It is used only to run the servers and is not shared. Questions and requests: contact@haulnet.cc.
  • Community servers are run by their operators, not by the Haulnet project. The project checks that a listed server answers and runs a current version; it does not control what an operator does with a server. Report a server through the server list.
  • The host's addresses travel to invited friends in the Steam lobby data, so they can connect.
  • Haulnet needs no administrator rights and changes no system settings or the hosts file.

Questions

Do my friends need Haulnet?
Yes. Everyone in a Haulnet game needs Haulnet and the same game version. Photon Cloud games still work with friends who do not have it.
Do all players need the same Haulnet version?
The same game version, yes: that is the game's own rule. Haulnet does not check which Haulnet version the others have. The invite carries the number of its format: Haulnet reads the current format and the one before it, and when the host's Haulnet writes a newer format than a friend's Haulnet knows, the friend's Haulnet notes it in BepInEx/LogOutput.log and tries to connect anyway. Use the latest release on every PC.
How many players can join an “On my PC” game?
The server that Haulnet starts on your PC accepts 20 connections, and every player, the host included, uses about two of them: one for the game and one for voice. That is room for about 10 players; the game's own player limit still applies.
My friend cannot join my “On my PC” game. Why?
Your friend's PC has no network path to yours. Most home connections cannot be reached from outside without help. Join the same Radmin VPN network (free, Windows) or a WireGuard network, or create the game on a Haulnet server, where nobody needs to reach your PC. Details: Reaching the host's PC.
I kicked a friend and now they are banned. Is that a bug?
No: in R.E.P.O. the kick button bans the player from the current game, with or without Haulnet. The ban ends when you return to the main menu and create a new game.
My friend cannot rejoin during a level.
That is the game's own rule: joining works in the lobby, not while a level runs, with or without Haulnet.
The game was updated. What happens to Haulnet?
If Haulnet does not recognise the new version, it switches itself off and you play through Photon Cloud as usual until a Haulnet update comes out. The message HAULNET IS OFF says so. When the update changed the part of the game that Haulnet redirects, there is no message: the HAULNET tab is absent and BepInEx/LogOutput.log says why (No HAULNET tab).
Which city should I pick?
The one with the lowest ping. Ping depends on your provider's route, not on distance: a player in Siberia measured a lower ping to Moscow than to Novosibirsk. Haulnet orders cities by your measured ping and their stability.
Who runs the servers? Do they cost anything?
Official servers are run by the Haulnet project; community servers by their operators, named in the list. Playing is free: the list's rules forbid ads, payments and player accounts.
Is Haulnet in my language?
Haulnet's own texts are in English, Russian and Ukrainian and follow the game's language; other languages show English. Translations are welcome on GitHub.
Does Haulnet support Linux, Steam Deck or Proton?
No. Haulnet is made for R.E.P.O. on Windows: hosting “On my PC” starts a Windows program, luxon_server.exe, next to the game. Linux and Steam Deck are not supported.
Does it work with other mods?
Haulnet only changes where the game connects and adds a tab to the region page. Mods that change the same menus or the connection may conflict; report it with both mods named.
Is it official?
No. Haulnet is an independent fan project, not affiliated with or endorsed by semiwork or Exit Games.
Does it work with a pirated copy?
No, and it never will: Haulnet is for people who own R.E.P.O. on Steam.
