Haulnet documentation

Haulnet is a free, open-source BepInEx mod for R.E.P.O. It lets a game live on your own PC, on a community server or on any server by address, instead of Photon Cloud.

How it works

R.E.P.O. uses Photon for multiplayer: every player connects to a Photon server, which relays the game between them. That server normally lives in Photon Cloud, even when both players sit in the same room. Haulnet points the game at a different, Photon-compatible server instead: LuxonServer, an open-source implementation.

  • On my PC: LuxonServer runs inside the host's game for as long as the lobby is open, like “Open to LAN”.
  • Community servers: people run the haulnet-server package on a VPS; the public list at servers.haulnet.cc shows them by city.
  • Server by address: any server you or a friend runs, listed or not.

The Steam invite carries where the game lives, so friends follow it as usual. Until you pick a Haulnet row on the region page, the game plays exactly as without the mod.

Privacy and safety

  • Haulnet sends no telemetry. It downloads the public server list, pings the listed servers and asks them for their status (counts and versions only).
  • Whoever runs the server of a game sees the players' IP addresses, as Photon does in Photon Cloud. On your PC that is you; on a community server it is its operator, shown in the list.
  • The host's addresses travel to invited friends in the Steam lobby data, so they can connect.
  • Haulnet needs no administrator rights and changes no system settings or the hosts file.

FAQ

Do my friends need Haulnet?
Yes, everyone in a Haulnet game needs Haulnet and the same game version. Photon Cloud games still work with friends who do not have it.
Does it work with other mods?
Haulnet only changes where the game connects and adds rows to the region page. Mods that change the same menus or the connection may conflict; report it with both mods named.
Is it official?
No. Haulnet is an independent fan project, not affiliated with or endorsed by semiwork or Exit Games.
Does it work with a pirated copy?
No, and it never will: Haulnet is for people who own R.E.P.O. on Steam.
