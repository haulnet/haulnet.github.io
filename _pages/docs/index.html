Haulnet documentation

Haulnet is a free, open-source mod for R.E.P.O. It lets a game live on your own PC, on a Haulnet server or on any server by address, instead of Photon Cloud.

It is useful when no Photon Cloud region is close to you (a Haulnet server can stand in any city), when you want a server of your own for your friends or for everyone, and when you want to play directly with friends from your own PC, with no server in between. Who it's for.

How it works

R.E.P.O. uses Photon for multiplayer: every player connects to a Photon server, which relays the game between them. That server normally lives in Photon Cloud, the game's online service, even when both players sit in the same room. Haulnet points the game at a different, Photon-compatible server instead: LuxonServer, an open-source implementation by its own author.

  • On my PC: the host's Haulnet starts LuxonServer next to the game when the host creates the game, and stops it when the host returns to the main menu, like Minecraft's “Open to LAN”.
  • Haulnet servers: the haulnet-server package on a VPS. The public list at servers.haulnet.cc shows official servers run by the Haulnet project and community servers, by city.
  • Server by address: any server you or a friend runs, listed or not.

The Steam invite carries where the game lives, so friends follow it as usual. Until you pick a row in the HAULNET tab, the game plays exactly as without the mod.

Tested so far: two players on two PCs on a Haulnet server and on the host's PC over Radmin VPN, on Windows. Not tested yet: the same home network, IPv6 or a forwarded port between two PCs; Linux, Proton and Steam Deck.

Privacy and safety

  • Haulnet sends no telemetry. It downloads the public server list, reads the servers' uptime from the Haulnet monitor (monitor.haulnet.cc), pings the listed servers and asks them for their status (counts and versions only).
  • Whoever runs the server of a game sees the players' IP addresses, as Photon does in Photon Cloud. On your PC that is you; on a listed server it is its operator, shown in the list.
  • The host's addresses travel to invited friends in the Steam lobby data, so they can connect.
  • Haulnet needs no administrator rights and changes no system settings or the hosts file.

Questions

Do my friends need Haulnet?
Yes. Everyone in a Haulnet game needs Haulnet and the same game version. Photon Cloud games still work with friends who do not have it.
My friend cannot join my “On my PC” game. Why?
Your friend's PC has no network path to yours. Most home connections cannot be reached from outside without help. Join the same Radmin VPN network (free, Windows; tested), or create the game on a Haulnet server, where nobody needs to reach your PC. Details: Reaching the host's PC.
I kicked a friend and now they are banned. Is that a bug?
No: in R.E.P.O. the kick button bans the player from the current game, with or without Haulnet. The ban ends when you return to the main menu and create a new game.
My friend cannot rejoin during a level.
That is the game's own rule: joining works in the lobby, not while a level runs, with or without Haulnet.
The game was updated. What happens to Haulnet?
If Haulnet does not recognise the new version, it switches itself off with the message HAULNET IS OFF and you play through Photon Cloud as usual until a Haulnet update comes out.
Which city should I pick?
The one with the lowest ping. Ping depends on your provider's route, not on distance: a player in Siberia measured a lower ping to Moscow than to Novosibirsk. Haulnet orders cities by your measured ping and their stability.
Who runs the servers? Do they cost anything?
Official servers are run by the Haulnet project; community servers by their operators, named in the list. Playing is free: the list's rules forbid ads, payments and player accounts.
Is Haulnet in my language?
Haulnet's own texts are in English, Russian and Ukrainian and follow the game's language; other languages show English. Translations are welcome on GitHub.
Does it work with other mods?
Haulnet only changes where the game connects and adds a tab to the region page. Mods that change the same menus or the connection may conflict; report it with both mods named.
Is it official?
No. Haulnet is an independent fan project, not affiliated with or endorsed by semiwork or Exit Games.
Does it work with a pirated copy?
No, and it never will: Haulnet is for people who own R.E.P.O. on Steam.
