Play R.E.P.O. with friends on a server you control.

Haulnet is a free mod that lets a game live on your own PC, on a community server or on any server by address instead of Photon Cloud. Low ping when you play nearby, no Photon account, no admin rights. Until you pick Haulnet, the game plays exactly as without the mod.

Source on GitHub Community servers

Three ways to play

All of them sit on the game's own region page, in a Haulnet tab next to the usual Photon Cloud regions.

On my PC

Like “Open to LAN”: a server starts inside your game on UDP 27000–27002. Friends reach you over the same network, any VPN you already use, IPv6 or a forwarded port.

Community servers

One row per city from the public server list, with live ping. Haulnet picks a working server of that city for you.

Server by address

Type host or host:port of a server you or a friend runs. It does not have to be listed anywhere.

Friends join the way they always do: accept the Steam invite. The invite tells their Haulnet where the game lives. Everyone in a Haulnet game needs Haulnet and the same game version.

Run a server

The Haulnet server package runs LuxonServer, an open-source Photon-compatible server, with a ready config and a small status endpoint. Docker, Linux and Windows. Keep it private and share the address, or add it to the public list with a pull request to haulnet-servers; CI checks every entry.

Install

The first release will come to Thunderstore (r2modman, Gale) with BepInEx as its only dependency. Until then, Haulnet is built from source. Haulnet is for people who own R.E.P.O. on Steam.
