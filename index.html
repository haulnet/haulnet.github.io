Play R.E.P.O. with friends on a server you control.

Haulnet is a free, open-source mod that lets a game live on your own PC, on a community server or on any server by address instead of Photon Cloud. No Photon account, no admin rights. Until you pick Haulnet, the game plays exactly as without the mod.

Three ways to play

All of them sit on the game's own region page, in a HAULNET tab next to the usual Photon Cloud regions. Friends join the way they always do: accept the Steam invite, which tells their Haulnet where the game lives.

On my PC

Like “Open to LAN”: a server starts inside your game on UDP 27000–27002. Friends reach you over the same network, any VPN you already use, IPv6 or a forwarded port.

Community servers

One row per city from the public server list, with live ping. Haulnet picks a working, compatible server of that city for you.

Server by address

Type host or host:port of a server you or a friend runs. It does not have to be listed anywhere.

Server operators

The haulnet-server package runs LuxonServer, an open-source Photon-compatible server, with a ready config and a status endpoint. Docker on Linux:

base=https://github.com/haulnet/haulnet-server/releases/latest/download
curl -fsSLO "$base/docker-compose.yml"
curl -fsSL -o haulnet-server.env "$base/haulnet-server.env.example"
nano haulnet-server.env   # set EXTERNAL_ADDRESS
docker compose up -d

Open UDP 27000–27002 and TCP 27080. Systemd and Windows: see the server docs. To list it publicly, open a pull request to haulnet-servers; CI checks every entry.

Principles

  • Off means off. In Photon Cloud or solo play the game behaves exactly as without the mod.
  • One package. The mod plus the standard BepInExPack; no system changes, no admin rights.
  • Explainable failures. When something does not work, the game tells you what and what to do.
  • Open source. MIT-licensed mod, server package and server list, built in public on GitHub.
