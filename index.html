Play R.E.P.O. with friends on a server you control.

R.E.P.O. runs every online game through Photon Cloud, even when friends sit in the same room. Haulnet is a free, open-source mod that lets the game live on your own PC, on a Haulnet server or on any server by address instead. No Photon account, no admin rights. Until you pick Haulnet, the game plays exactly as without the mod.

Who it's for

When Photon Cloud is not the best place to play

01

Far from Photon's regions

The game lets you pick only Photon Cloud's regions. When none of them is close, every game has high ping. A Haulnet server can stand in any city (today Moscow, Novosibirsk and Vladivostok) and anyone can add one closer to their players.

Measured once from a home connection in Russia: Photon Cloud Europe 96 ms, the Haulnet server in Moscow 54 ms.

02

Your own server

Run the free haulnet-server package on a VPS or a machine at home: your hardware, your limits, your name. Keep it for your friends, or list it so that every Haulnet player can use it.

Private or public?

03

Same room or Radmin VPN

R.E.P.O. has no local mode. With On my PC the host's PC is the server and friends connect straight to it, like Minecraft's “Open to LAN”: over your home network, or from anywhere through Radmin VPN, a free virtual local network that links your PCs directly when it can.

Tested with two PCs over Radmin VPN; the same home network is not tested yet.

Three ways to play

Pick where the game lives

All three sit on the game's own region page, in a HAULNET tab next to the usual Photon Cloud regions. Friends join the way they always do: accept the Steam invite, which tells their Haulnet where the game lives.

On my PC

Like Minecraft's “Open to LAN”: a server starts next to your game on UDP 27000–27002. Friends reach your PC through Radmin VPN (tested with two PCs); the same home network, IPv6 or a forwarded port can work too (not tested yet).

Haulnet servers

One row per city from the public server list: official servers and community ones, with live ping. Haulnet picks a working, compatible server of that city for you.

Server by address

Type host or host:port of a server you or a friend runs. It does not have to be listed anywhere.

Get started

Up and running in three steps

Players

    {{players_steps}}

Everyone in a Haulnet game needs Haulnet and the same game version. Haulnet is for people who own R.E.P.O. on Steam, on Windows. More: Install · Play · Troubleshooting · Questions.

Server operators

The haulnet-server package runs LuxonServer, an open-source Photon-compatible server, with a ready config for R.E.P.O.

  1. Take a Linux VPS with Docker or systemd, or a Windows PC, with a public IPv4 address.
  2. Download the release, set EXTERNAL_ADDRESS, start it and open UDP 27000–27002 and TCP 27080.
  3. Share the address with friends, or add the server to the public list with one pull request: a listed server must stay online around the clock (private or public?).

Principles

Built to stay out of your way

  • Off means off. In Photon Cloud or solo play the game behaves exactly as without the mod.
  • One package. The mod plus the standard BepInExPack; no system changes, no admin rights.
  • Explainable failures. When something does not work, the game tells you what and what to do.
  • Open source. MIT-licensed mod, server package and server list, built in public on GitHub.
